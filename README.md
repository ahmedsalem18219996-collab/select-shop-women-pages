# SELECT SHOP WOMEN — storefront and Admin

The live SELECT SHOP WOMEN site (women's clothing, Egypt, Cash on Delivery): https://selectshopeg.com/ · Admin: https://selectshopeg.com/admin/

- Static HTML/CSS/vanilla JS (ES modules) published by GitHub Pages. No framework, no application server.
- Branch `release` is production: merging into it deploys the site automatically. Work on a branch and open a PR to `release`; the owner approves every merge.
- Design: Soft Luxury (Ivory, Mauve, Dusty Rose, Champagne, Ink Plum), Egyptian Arabic, RTL, mobile-first.
- Backend (products, prices, orders, shipping, media, Owner/Staff access): the private repo `select-shop-women-staging` and its Supabase WOMEN project. Prices and totals always come from the server.
- Landing pages `lp/<id>/` are generated by `tooling/build-lp.mjs` from `tooling/pages/*.json`; tests and Lighthouse live in `tooling/`.
- No secrets, keys or customer data belong in this repo. `SELECT-SHOP-CLEAN` is a separate project and is never mixed in.

Before changing anything read [`CLAUDE.md`](CLAUDE.md) (rules and quality gate) and [`docs/HANDOVER-2026-11-05.md`](docs/HANDOVER-2026-11-05.md) (full background, open risks).
